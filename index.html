☁️ Salvar pedidos online (GitHub)

Guarda cada pedido finalizado num repositório privado do GitHub, para ver em qualquer aparelho. Faça isso uma vez em cada aparelho.

  1. No GitHub, crie um repositório privado (ex.: CDT-Atacado-Pedidos) com um README.
  2. Crie um token em Settings → Developer settings → Fine-grained tokens, só para esse repositório, com permissão Contents: Read and write.
  3. Cole abaixo o repositório e o token.
